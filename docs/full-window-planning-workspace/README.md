# Full-window planning workspace

This folder contains the product direction for Slate’s next major desktop surface: a spacious planning workspace for shaping commitments while the menu-bar popover remains focused on deciding what fits today.

## Documents

- [Full-window planning workspace](full-window-planning-workspace.md) — the core product direction, board model, domain boundary, guardrails, and roadmap criteria.
- [Elevated improvements](elevated-improvements.md) — research-informed ideas for making the workspace more distinctive, useful, and native to macOS.

## Recommended reading order

1. Read the core direction first.
2. Use the elevated improvements write-up to prioritize the strongest desktop interactions.
3. Validate any implementation proposal against the roadmap entry and the product brief.

## Source of truth

The roadmap determines sequencing and evidence gates. The documents in this folder describe the direction and candidate experience; they do not authorize expanding the task model beyond the stated boundaries.
