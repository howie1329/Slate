# Slate v1.0.1

Slate v1.0.1 is a small post-1.0 release focused on helping new users understand the core daily planning loop.

## Added

- A short, skippable first-run onboarding flow.
- Guided setup for daily capacity, Backlog capture, task estimates, and Today commitments.
- Persistent onboarding completion/skip state in the existing local SQLite settings store.

## Preserved

- Existing tasks, settings, API-key storage, and planner behavior remain unchanged for returning users.
- Manual planning remains fully local and does not require an AI provider or network connection.

## Distribution

- Apple Silicon macOS application, macOS 13.5 or later.
- Ad-hoc-signed DMG; macOS may require approval under System Settings → Privacy & Security → Open Anyway.
- Verify the downloaded DMG with the accompanying SHA-256 checksum.
