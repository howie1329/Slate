# Slate v1.1.0

## Added

- Configurable global quick capture from macOS with the recommended `⌘⇧Space` shortcut.
- Title-only capture into Backlog with persisted shortcut settings and short-lived in-process drafts.
- Revision-safe Undo backed by `manual-quick-capture-undo` Planner Events.

## Deferred

- Clipboard, selected-text, application, URL, file, AI-enriched, tagged, and destination-specific capture.
- End-of-day review and changed-capacity recovery flows remain later Stage 2 slices.
