# Slate v1.1.0

## Added

- Configurable global quick capture from macOS with the recommended `⌘⇧Space` shortcut and a dedicated compact capture window.
- Condensed two-line command-bar UI at 520 × 100 (360 × 100 minimum) with a separate Add action, Backlog/status line, pending feedback, and bounded Undo.
- Title-only capture into Backlog with persisted shortcut settings, short-lived in-process drafts, and inline success/Undo feedback.
- Revision-safe Undo backed by `manual-quick-capture-undo` Planner Events.

## Deferred

- Clipboard, selected-text, application, URL, file, AI-enriched, tagged, and destination-specific capture.
- End-of-day review and changed-capacity recovery remain conditional full-window 2.3 candidates; they are not required in the menu-bar popover.
