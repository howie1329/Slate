# Issue tracker: Local Markdown

Issues and specs for this repo live as markdown files in `docs/plans/`.

## Conventions

- One plan or issue per markdown file in `docs/plans/`.
- Preserve the existing numbered naming convention where applicable.
- Triage state is recorded with a `Status:` line near the top of each file.
- Comments and conversation history append to the bottom of the file under a `## Comments` heading.

## When a skill says "publish to the issue tracker"

Create or update a markdown file under `docs/plans/`, using the existing plan naming and structure conventions.

## When a skill says "fetch the relevant ticket"

Read the referenced markdown file from `docs/plans/`. The user will normally provide the path or issue number directly.
